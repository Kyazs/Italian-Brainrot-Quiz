# Italian Brainrot Quiz Meme

## Description
Italian Brainrot Quiz Meme is a humorous, interactive web application that tests users' knowledge of Italian culture, language, and memes in an entertaining way. This project combines educational content about Italy with internet humor to create an engaging quiz experience.

## Features
- Multiple-choice questions about Italian culture, language, and popular memes
- Shareable results for social media
- Progressive difficulty levels from "Skill issue Brainrotter" to "Supreme Gooning Braindead Master"
- Responsive design for both desktop and mobile devices

## Installation
1. Clone this repository
2. Run `npm install` to install dependencies
3. Run `npm start` to launch the development server
4. Open your browser and navigate to `http://localhost:3000`

## Technologies Used
- React.js
- CSS/SCSS
- Local Storage for saving scores
- React Router for navigation
